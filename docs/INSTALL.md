# Установка singbox_flutter (macOS)

Приложение не нотаризовано Apple (тестовая раздача), поэтому при первом открытии
macOS покажет предупреждение — это нормально, ниже как его пройти.

## Шаги

1. Скачайте `SingboxFlutter-<версия>.pkg`.
2. **Правый клик по файлу .pkg → «Открыть»** (двойной клик заблокирует Gatekeeper).
   В диалоге подтвердите «Открыть».
3. Пройдите установщик, введите **пароль администратора** — он нужен, чтобы
   установить системный сервис (helper), который поднимает VPN-туннель.
4. Откройте приложение из `/Applications`. Если macOS снова предупреждает —
   **правый клик по приложению → «Открыть»** один раз.

## Что входит в бандл

Внутри `.app/Contents/Resources` лежат два движка: `sing-box` (владеет туннелем,
роутингом, DNS и статистикой) и `xray`. Второй запускается не всегда — только для
нод `hysteria2` и `vless+xhttp`, которые sing-box не тянет; в остальных случаях
процесс xray не стартует вовсе.

## Если приложение не открывается

Выполните в Терминале (снимает «карантин» со скачанного файла):

```bash
xattr -dr com.apple.quarantine /Applications/singbox_flutter.app
```

## Проверка, что системный сервис установлен

```bash
launchctl print system/com.singboxclient.helper
```

Если выводит данные сервиса — всё установлено. Если «Could not find service» —
переустановите .pkg (шаг 2-3).

## Удаление

Запросите у разработчика `scripts/uninstall.sh` или удалите вручную:
приложение из `/Applications`, файлы
`/Library/LaunchDaemons/com.singboxclient.helper.plist` и
`/Library/PrivilegedHelperTools/com.singboxclient.helper` (через `sudo`).
