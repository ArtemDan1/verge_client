# Verge

### Современный прокси-клиент для macOS

Подключайте подписку, выбирайте сервер и управляйте маршрутизацией — без ручной сборки конфигов и работы с терминалом.

Работает на базе **sing-box** и **Xray**.

## О Verge

Verge — настольный клиент для безопасного и управляемого доступа в интернет. Он принимает готовые подписки и отдельные share-ссылки, автоматически преобразует их в рабочую конфигурацию, запускает подходящий сетевой движок и берёт на себя системный прокси, TUN-интерфейс, DNS и правила маршрутизации.

Приложение рассчитано как на обычное подключение в пару кликов, так и на тонкую настройку сети: можно выбрать, какие домены и приложения направлять через прокси, какие открывать напрямую, а какие блокировать.

Сейчас Verge доступен для **macOS на Apple Silicon и Intel**.

## Возможности

- **Быстрое подключение** — импорт подписки или конфигурации и запуск из одного приложения.
- **Подписки и отдельные ноды** — поддержка sing-box JSON, Xray/V2Ray JSON, base64-списков и share-ссылок.
- **Совместимость с панелями** — обработка стандартных subscription-заголовков и подписок с HWID-привязкой, включая Remnawave.
- **Два режима работы**:
  - **System Proxy** — проксирование поддерживаемых приложений через системные настройки macOS;
  - **TUN** — перенаправление всего системного трафика через привилегированный helper.
- **Умный выбор движка** — sing-box используется по умолчанию, Xray запускается только для конфигураций, которым он действительно нужен.
- **Поддерживаемые протоколы** — VLESS, VMess, Trojan, Shadowsocks, Hysteria2 и NaiveProxy; возможности конкретной ноды зависят от её транспорта и выбранного движка.
- **Маршрутизация** — профили direct / proxy / block, локальные GeoIP/Geosite rule sets и готовые сценарии вроде полного проксирования, обхода российских ресурсов и блокировки рекламы.
- **Проверка серверов** — измерение задержки, тест доступности и автоматический выбор подходящей ноды.
- **Контроль соединения** — текущая скорость, переданный трафик, активные подключения, журналы sing-box, Xray и самого приложения.
- **Автообновление подписок** — индивидуальный интервал обновления профилей и отображение лимита трафика и срока действия.
- **Deep links** — добавление подписки по ссылке вида `verge://import/...`.
- **Обновления приложения** — проверка GitHub Releases и загрузка нового PKG прямо из Verge.
- **Системный трей и темы** — быстрый доступ к состоянию клиента, светлая и тёмная темы.

## Как это работает

1. Добавьте ссылку на подписку или вставьте конфигурацию.
2. Выберите профиль и сервер — либо включите автоматический выбор.
3. Выберите режим System Proxy или TUN.
4. Нажмите подключение. Verge сам соберёт конфигурацию и запустит нужный движок.

Ваши профили и настройки хранятся локально на устройстве. Локальный Clash API, используемый для статистики, слушает только loopback и получает новый порт и секрет при каждом запуске.

## Установка

1. Откройте раздел [Releases](https://github.com/ArtemDan1/verge_client/releases).
2. Скачайте PKG последней версии.
3. Откройте установщик и следуйте его инструкциям.
4. Запустите Verge из папки Applications.

Сборка пока не нотаризована Apple. Если Gatekeeper блокирует запуск, используйте **правый клик → Открыть**. Подробная инструкция и диагностика находятся в [docs/INSTALL.md](docs/INSTALL.md).

> Для установки системного helper и работы TUN потребуется пароль администратора macOS.

## Поддерживаемые форматы

| Источник | Примеры |
|---|---|
| Подписки | HTTP/HTTPS URL, base64-списки |
| Готовые конфигурации | sing-box JSON, Xray/V2Ray JSON |
| Share-ссылки | `vless://`, `hysteria2://`, `hy2://`, `naive+https://` |
| Интеграции | `verge://import/...` |

Поддержка конкретного транспорта определяется актуальными возможностями встроенных версий sing-box и Xray.

## Разработка

Verge написан на Flutter. Интерфейс построен на `shadcn_ui`, общая логика приложения — на Dart, а системная интеграция macOS и привилегированный helper — на Swift.

```bash
flutter pub get
flutter run -d macos
flutter test
flutter analyze
```

### Структура проекта

```text
lib/
  app/          состояние приложения, подключение и фоновые задачи
  models/       профили, ноды, маршруты и настройки
  services/     подписки, парсеры, конфигурации, тесты и обновления
  platform/     мост между Flutter и macOS
  tunnel/       System Proxy и TUN
  storage/      локальное хранение состояния
  ui/           экраны и компоненты интерфейса
macos/
  Runner/       системная интеграция macOS
  Helper/       привилегированный helper для TUN
packaging/      файлы сборки PKG и LaunchDaemon
scripts/        сборка, установка и удаление
assets/         брендинг и rule sets
docs/           пользовательская и техническая документация
```

### Сборка PKG

```bash
scripts/build_release.sh
scripts/make_pkg.sh
scripts/install_and_verify.sh
```

Удаление тестовой сборки:

```bash
scripts/uninstall.sh
```

## Статус проекта

Verge находится в активной разработке. Сейчас основной и поддерживаемой платформой является macOS; каталоги других платформ могут присутствовать в репозитории, но не считаются готовыми релизами.

Если вы нашли ошибку или хотите предложить функцию, создайте [Issue](https://github.com/ArtemDan1/verge_client/issues).
